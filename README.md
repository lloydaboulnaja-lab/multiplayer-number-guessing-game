# Multiplayer Number Guessing Game

## Description
A console-based multiplayer number guessing game built using Python.
Players take turns attempting to guess a randomly generated number.

## Features
- Multiplayer support
- Input validation
- Random number generation
- Structured test documentation

## How to Run
1. Clone the repository
2. Run the Python file using Python 3

## Testing
Testing was conducted using structured validation methods.
Full test log available in the /docs folder.
